Overview

Lot/Serial Number(s) Selector in Point of Sale (POS)

  • By using this module you can select various Lots/Serial numbers from the current Location of Point of Sale easily.

  • Generally, the default Odoo doesn't let you pick specific lots/Serial numbers at the point of sale. In other words, it doesn't load lists of lots or serial numbers into the point of sale. Instead, it makes new lots/Serial numbers based on the information it gets from the point of sale orders.

  • This module will help users double-check what items are in stock for a particular lot/Serial number. It also helps to subtract items from that specific lot/Serial number.

Configuration

To use this module first install ‘POS Lot/Serial number Selection’ module

Inventory Setting Configuration

Enable Lots/Serial numbers and Serial numbers from Go to Inventory Module -> Configuration -> Settings -> Traceability -> Lots/Serial numbers

Configuration for POS Shop/Restaurant

Go to POS Dashboard -> Click on dropdown menu for POS Shop/Restaurant -> Click on Edit button

Enable Lot/Serial Number(s) Restrict On POS then Save it

Configuration for POS Lot number

Product Configuration

Check Product and enable the tracking of Product by Lot number.

Click on "On Hand" to add product Lot and its quantity.

POS Lot Selection

User can add Lot number from list of Lot number

Select lot number and click on ‘Ok’ button

Sale Order will be generated of selected lot and quantity.

Validation

If a user tries to create a Lot number manually from the point of sale, the system will show an error “Some of the entered Lot numbers are invalid.”

If a user tries to create a Sale Order without selecting the Lot number, the system will show an error “Please enter at least one Lot number is required.”

Configuration for POS Unique Serial number

Check Product and enable the tracking of Product by Unique Serial number.

Click on "On Hand" to add the product Serial number and its quantity.

POS Serial number Selection

User can add Serial number from list of Lot number

Select Serial number and click on ‘Ok’ button

Sale Order will be generated of selected Serial number and quantity.

Validation

If a user tries to create a Serial number manually from the point of sale, the system will show an error “Some of the entered Serial numbers are invalid.”

If a user tries to create a Sale Order without selecting the Serial number, the system will show an error “Please enter at least one Serial number is required.”
